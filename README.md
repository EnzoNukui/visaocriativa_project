# Sistema de Gerenciamento de Uniformes

O Sistema de Gerenciamento de Uniformes é uma aplicação desenvolvida para auxiliar no controle, organização e acompanhamento da distribuição de uniformes dentro de uma organização.

O projeto surgiu a partir da identificação de um problema real no ambiente de trabalho, onde o controle de uniformes era realizado de forma manual, utilizando planilhas ou registros informais. Esse tipo de processo pode gerar dificuldades no acompanhamento do estoque, erros no registro de entregas e falta de organização das informações.

A partir dessa necessidade, foi desenvolvida uma solução digital com o objetivo de tornar esse processo mais estruturado e eficiente. A aplicação permite centralizar as informações relacionadas aos uniformes, facilitando tanto o controle do estoque quanto o registro das entregas realizadas.

Com o sistema, é possível realizar o cadastro de uniformes, acompanhar a quantidade disponível em estoque, registrar as entregas realizadas e consultar as informações de forma organizada. Dessa forma, a aplicação contribui para uma gestão mais clara e eficiente dos uniformes dentro da organização.

Além de resolver um problema prático, o desenvolvimento deste projeto também contribuiu para o aprimoramento de habilidades relacionadas à lógica de programação, modelagem de sistemas, organização de dados e resolução de problemas através da tecnologia.
